# Gym Pro

Premium offline-first Android workout tracker.

## Current features
- Dynamic training-day builder
- Exercises with working sets, target reps and alternatives
- Global weight sync by exercise name across all routines and alternatives
- Live workout mode with set completion and configurable rest timer
- Workout history, duration, completed sets and volume
- Local persistent storage — no server or paid API required
- JSON backup export/import
- Premium dark mobile UI
- GitHub Actions workflow that builds an installable debug APK

## Build
Push to `main` or run **Build Gym Pro APK** manually from the Actions tab.  
After the workflow succeeds, download the **Gym-Pro-APK** artifact.

Android package: `com.ahmed.gympro`
